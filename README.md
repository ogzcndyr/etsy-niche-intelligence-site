# Etsy Niche Intelligence — Public project page

This repository hosts the public informational website for the **Etsy Niche Intelligence** personal research project. It does not contain the private application code, credentials, or API keys.

## Publish with GitHub Pages

1. Create a **public** repository, for example `etsy-niche-intelligence-site`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Wait for GitHub Pages to publish the website. The URL will typically be `https://YOUR_USERNAME.github.io/etsy-niche-intelligence-site/`.

The site is static and does not collect visitor data. Do not commit API keys, `.env` files, or private application code here.
